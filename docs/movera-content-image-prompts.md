# MOVERA content media brief

## Shared art direction

Create a premium editorial photograph for a Belgian mobility-intelligence company. Light, contemporary European atmosphere; confident but credible technology; cool neutral base with one distinct accent colour; natural daylight; clean cinematic composition; room for responsive editorial cropping; realistic materials and people; no logos, legible text, watermarks, science-fiction holograms, decorative data lines, or generic blue-only grading. Landscape 16:10.
